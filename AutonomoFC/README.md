# AutonomoFC — Proyecto final RoboCup Soccer Simulation 2D

Objetivo: validar el comportamiento de jugadores virtuales autónomos en el
servidor oficial `rcssserver` (https://github.com/rcsoccersim/rcssserver).

## Preparar el entorno

```
./scripts/instalar_servidor.sh
```
